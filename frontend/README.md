# Hackathon Admin Tracker

A modern, responsive React admin dashboard for managing a single hackathon event. Create teams, manage members, grade submissions, and view leaderboards.

## Features

✅ **Dashboard** - Overview of all teams with quick stats
✅ **Team Management** - Create, edit, and delete teams
✅ **Marking System** - Grade teams on 4 criteria (Innovation, Implementation, Design, Presentation)
✅ **Leaderboard** - Auto-ranked teams with scores
✅ **Responsive Design** - Works on desktop and mobile
✅ **Admin Only** - Simplified interface for admin operations

## Marking Criteria

| Criteria       | Max Points |
| -------------- | ---------- |
| Innovation     | 25         |
| Implementation | 25         |
| Design & UX    | 25         |
| Presentation   | 25         |
| **Total**      | **100**    |

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```
